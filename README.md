# Free Tutor Connect

An AI-powered tutoring platform connecting students with 
intelligent tutors — supporting 16 languages, voice 
interaction, and whiteboard teaching. Completely free.

🌐 Live Demo: https://statuesque-torrone-d21e09.netlify.app

## Features
- 🤖 AI Tutor with Voice & Text interaction
- 🌍 16 Languages with RTL support (Urdu, Arabic)
- 📋 Interactive Whiteboard Teaching
- 🎯 Step-by-step explanations
- 🌙 Dark / Light Mode
- 📱 Fully Mobile Responsive

## Tech Stack
- React 18 + Vite
- Tailwind CSS
- React Router v6
- Web Speech API
- TypeScript

## Run Locally
git clone https://github.com/zara029/english-urdu-ai.git
cd english-urdu-ai
npm install
npm run dev
